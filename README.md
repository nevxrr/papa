# СТРОПА — Производство ошейников

Внутренний веб-инструмент для цеха: карточки заказов, статусы, чек-листы с фотофиксацией и склад материалов.

## Онлайн

После merge в `main` сайт сам деплоится на GitHub Pages:

**https://nevxrr.github.io/papa/**

Один раз в репозитории: **Settings → Pages → Source → GitHub Actions**.

## Запуск локально

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Возможности

- **Заказы** — тип, размер, материал, цвет, срок, ответственный
- **Статусы** — Принят → В работе → Готов к выдаче → Отгружен
- **Этапы** — нарезка, прошивка, фурнитура + фото с камеры
- **Склад** — остатки строп/пряжек/карабинов и уведомления о низком остатке

Данные хранятся локально в браузере (`localStorage`).
